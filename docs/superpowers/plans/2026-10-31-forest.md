# Couche forêt (lot R5b) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter une couche « Forest » (couvert 2000 au-dessus de 30 %, pertes 2001–2024 colorées par année) en tuiles fines jusqu'au niveau 8, avec tooltip, légende double, crédit CC BY 4.0 et quatre pages d'entrée.

**Architecture:** Un nouveau jeu de tuiles `forest` (pyramide géodésique existante, 512 px, niveaux 0–8, index de présence `index.bin`) généré une fois par an par un workflow Actions manuel, à partir des dalles Hansen GFC-2024-v1.12 lues sur Google Cloud Storage, et publié sur R2 sous `tiles/forest/v1.12/`. Le module Python `tiler/forest.py` (pur numpy) agrège 30 m → résolution de tuile et encode deux canaux (couvert %, année de perte) ; `tiler/hansen.py` lit les dalles par GDAL. Côté front, une « couche tuiles » à côté des couches « grille » : un second `TileLoader` pour le jeu `forest`, un uniform de patch dans `patch.frag.glsl`, la frise masquée, une légende double, un tooltip qui lit la tuile sous le curseur.

**Tech Stack:** Python 3.12, numpy, Pillow, GDAL CLI (Actions), rclone ; Vite 8, TypeScript 5.9, Three.js 0.185, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-10-31-forest-design.md` (lire en entier avant toute tâche).

## Review Focus

1. **Tuile absente ou pas encore chargée** sous le curseur : le tooltip ne doit jamais afficher une valeur d'une autre tuile ou d'un niveau trop grossier comme si elle était exacte ; il peut lire l'ancêtre chargé (valeur agrégée) mais pas inventer — testé en Task 6.
2. **Passage Forest → couche météo → Forest** : la frise revient exactement dans son état (instant, lecture), la couche météo redevient visible, le jeu `forest` cesse d'être échantillonné — testé en Task 5.
3. **Niveau 8 absent hors tropiques** (repli stockage) : le globe affiche l'ancêtre de niveau 7 sans trou ni requête 404 répétée — testé en Task 5 (index) et vérifié en Task 8.
4. **Dalle Hansen manquante ou téléchargement interrompu** pendant la génération : le job échoue bruyamment ou reprend, jamais un trou silencieux publié comme « pas de forêt » — testé en Task 3.
5. **Antiméridien et bords de dalles** (lon ±180, jonctions 10°) : pas de couture visible ni de bloc décalé — testé en Task 2 (lecture de bloc à cheval sur deux dalles).

### Task 1 : Agrégation et encodage d'une tuile forêt (`tiler/forest.py`, pur numpy)

**Files:**
- Create: `tiler/forest.py`, `tests/tiler/test_forest.py`

**Interfaces:**
- Produces :
  - `FOREST_THRESHOLD = 30`
  - `aggregate(cover: np.ndarray, loss: np.ndarray, factor: int) -> tuple[np.ndarray, np.ndarray]` : entrées uint8 (H, W) à 30 m alignées, `H` et `W` multiples de `factor` ; sorties uint8 (H/factor, W/factor) : **couvert** = moyenne de `cover` sur les pixels `≥ FOREST_THRESHOLD` du bloc (0 si aucun) ; **année** = règle d'agrégation des pertes, choisie et justifiée par l'implémenteur (par exemple : année la plus récente parmi les pixels forêt perdus si leur part ≥ un seuil documenté, sinon 0) — la justification va dans la docstring et dans le rapport.
  - `encode_tile(cover: np.ndarray, year: np.ndarray) -> np.ndarray` : tableau uint8 (512, 512, C) prêt pour `cut.write_png` ; format des canaux au choix (gris + alpha, ou RGB avec un canal à 0) mais **documenté** pour la Task 5 (constante `CHANNELS` décrivant quel canal porte quoi).
  - `is_empty_tile(tile: np.ndarray) -> bool` : ni forêt ni perte.
- [ ] **Step 1 : Tests** : seuil (bloc de pixels à 29 → couvert 0 ; à 30 → 30) ; moyenne seulement sur les pixels forêt ; perte sur un pixel non forêt ignorée ; règle d'année (au moins deux cas qui fixent la règle choisie) ; `factor = 1` est l'identité au seuil près ; `encode_tile` round-trip (relire les canaux) ; `is_empty_tile` vrai sur des zéros, faux avec un seul pixel de forêt.
- [ ] **Step 2 :** `.venv/Scripts/python -m pytest tests/tiler/test_forest.py -q` → échecs.
- [ ] **Step 3 :** implémenter ; un tableau de 4096 × 4096 doit s'agréger sans copie superflue (reshape + réductions).
- [ ] **Step 4 :** verts ; suite complète `-q`.
- [ ] **Step 5 : Commit** `feat(tiler): agrégation et encodage des tuiles forêt (seuil 30 %)`.
