# Couche neige (lot R5a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter une couche « Snow » à deux modes (Snowfall : cumul prévu depuis l'heure du run ; Depth : épaisseur au sol) et quatre pages d'entrée neige.

**Architecture:** Une troisième source NOMADS, `gfs_snow`, **secondaire** (même filtre et mêmes runs que GFS, téléchargement séparé limité à `APCP`/`CPOFP`/`SNOD`), publie deux couches au contrat v3 inchangé : `snow_depth` (lecture directe) et `snowfall` (couche dérivée, cumul calculé échéance par échéance par `pipeline/snow.py`, état flottant gardé sur R2 pour les reprises). Son échec ne touche jamais les couches GFS (report des couches précédentes, comme `gefs_chem`). Côté front, deux `LayerDef` dont l'une (`snow_depth`) est un « mode » de l'autre : une seule entrée de menu, un sélecteur de mode à côté de la légende.

**Tech Stack:** Python 3.12 (eccodes, numpy, Pillow) ; Vite 8, TypeScript 5.9, Three.js 0.185, Vitest 4.

**Spec:** `docs/superpowers/specs/2026-10-31-snow-design.md` (lire en entier avant toute tâche).

- Unité cm, une décimale sous 10 cm, entier jusqu'à 1 m, puis mètres une décimale sous 10 m et entier au-delà (« 7.4 m », « 32 m »).
- Ratio neige/eau **10:1** ; cumul **depuis l'heure du run (f000)**.

## Review Focus

1. **Reprise au milieu d'une frise** : un run commencé à un passage et terminé au suivant (cas courant : NOMADS publie les échéances au fil de l'eau) doit produire des PNG `snowfall` identiques à un run d'une traite — testé en Task 3.
2. **Fichier d'état absent ou incohérent** (premier déploiement avec des PNG neige déjà là, état d'un autre run, état corrompu) : recalcul depuis f003, jamais un cumul repartant de zéro au milieu — testé en Task 3.
3. **`CPOFP = −50`** (sentinelle « pas de précipitation ») et `ΔAPCP` légèrement négatif (bruit d'arrondi GRIB) : jamais de neige négative ni de part gelée > 1 — testé en Task 2.
4. **Neige indisponible mais l'autre mode disponible** (une seule des deux couches dans le manifeste, ou une en échec de chargement) : l'entrée Snow reste utilisable et ouvre le mode disponible — testé en Task 4.
5. **Bascule de mode sur une page région** (Alpes → Depth → Snowfall) : on reste sur la page région, la caméra et l'instant de la frise ne bougent pas — testé en Task 5.

### Task 2 : Calcul des chutes (`pipeline/snow.py`, pur numpy)

**Files:**
- Modify: `pipeline/snow.py`
- Test: `tests/pipeline/test_snow.py` (nouveau)

**Interfaces:**
- Consumes: `snow.CPOFP` (Task 1).
- Produces :
  - `SNOW_RATIO = 10.0`
  - `frozen_fraction(cpofp_pct: np.ndarray) -> np.ndarray` : `clip(cpofp, 0, 100) / 100` (la sentinelle −50 donne 0).
  - `@dataclass(frozen=True) class SnowState: fh: int; apcp_mm: np.ndarray; cum_cm: np.ndarray` (grilles brutes 721 × 1440, float32, **non réorientées**).
  - `start() -> SnowState` : `fh=0`, zéros.
  - `advance(state: SnowState, fh: int, apcp_mm: np.ndarray, cpofp_pct: np.ndarray) -> SnowState` : `ΔP = max(apcp_mm − state.apcp_mm, 0)` ; `cum_cm = state.cum_cm + ΔP × frozen_fraction(cpofp_pct) × SNOW_RATIO / 10` (mm d'eau → mm de neige × 10, puis mm → cm : 1 mm d'eau = 1 cm de neige) ; lève `ValueError` si `fh <= state.fh`.
  - `encode_state(s: SnowState) -> bytes` / `decode_state(b: bytes) -> SnowState` : `np.savez_compressed` (clés `fh`, `apcp_mm`, `cum_cm`) ; `decode_state` lève `ValueError` sur toute donnée illisible ou de forme ≠ (721, 1440).
  - `state_key(run: datetime) -> str` = `f"{config.LAYERS_PREFIX}/{run_dir(run)}/gfs_snow_state.npz"` (dans le dossier du run : la rétention l'efface avec lui).

Choix de la part gelée : `CPOFP` instantané à `fh` (le plus simple). Si la comparaison avec `WEASD` de la Task 7 le montre trop faux, le changer ici seul (interface inchangée).
